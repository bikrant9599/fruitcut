# Game Assets Directory

Place your custom audio effects, ambient soundtracks, retro fonts, or custom sprite graphics in this directory. 

## Audio Effects (Placeholders):
- `assets/slice.wav` - Played on a successful fruit chop
- `assets/splat.wav` - Played on juice splashes
- `assets/explosion.wav` - Played on slicing bombs
- `assets/gong.wav` - Played on Game Over states

## Configurable Layout:
Modify `game.py` to point to actual filenames using `pygame.mixer.Sound("assets/slice.wav")` to fully activate custom haptic/sound feedback on your machine!
